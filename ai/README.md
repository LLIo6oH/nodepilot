# AI Workflow System

This `ai/` directory defines a lightweight AI-assisted engineering workflow for NodePilot.

It exists to improve repository consistency, maintain architecture boundaries, and keep implementation aligned with the 8-hour MVP scope.

Principles:
- Keep scope explicit and small.
- Preserve backend/frontend/runtime/tool boundaries.
- Prioritize runtime safety and predictable behavior.
- Prefer vertical slices over broad refactors.
- Use AI to accelerate disciplined engineering, not autonomous development.
